# 복불복

여럿이(2~10명) 폰 하나를 돌려 가며 하는 복불복 게임 모음. 설치형 웹앱(PWA)이라 빌드 과정이 없다.

| 게임 | 방식 |
| --- | --- |
| 사다리 타기 | 각자 출발 자리를 고르면 사다리와 결과가 만들어지고, 한 명씩 내려간다 |
| 룰렛 | 참가자 이름이 적힌 판을 돌려 화살표에 멈춘 사람이 당첨 |
| 달리기 경주 | 모두 동시에 출발해 꼴찌로 남는 사람이 당첨 |
| 의자 뺏기 | 음악에 맞춰 의자 둘레를 돌다가 음악이 멈추면 다 같이 앉고, 못 앉은 사람이 당첨 |

게임마다 25% 확률로 깜짝 이벤트가 나온다(사다리가 더 길어짐, 룰렛이 한 바퀴 더 돎, 달리기 부스터, 의자 뺏기 가짜 멈춤). 결과는 이벤트와 무관하게 먼저 정해지므로 확률은 언제나 1/n 이다. 확률은 `app.js`의 `SURPRISE`에서 바꾼다.

홈 화면에서 참가자 이름과 캐릭터(얼굴)를 정하고 게임을 고른다. 한 판에 한 명이 당첨되고, 결과는 당첨자 색의 전체 화면으로 공개된다. 참가자 목록과 전적은 폰(브라우저 저장소)에 저장된다. 전적은 날짜별로 계속 쌓이고, 홈 화면의 **지난 기록 보기**에서 기간별(전체·30일·7일) 순위와 날짜별 기록을 볼 수 있다. 지우기 전까지 남는다(앱 삭제·브라우저 데이터 삭제 시에는 사라짐). 효과음은 파일 없이 합성하고 홈 화면 오른쪽 위 버튼으로 끌 수 있다.

## 폰에 설치

1. GitHub 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장
2. 폰 크롬에서 `https://bluelevel.github.io/ai-game-studio/` 열기
3. 메뉴(⋮) → **홈 화면에 추가** (또는 **앱 설치**)

한 번 열어 두면 오프라인에서도 실행된다.

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 구조

- `index.html`, `style.css`, `app.js` — 화면과 게임 전부
- `sw.js`, `manifest.webmanifest`, `icons/` — 설치·오프라인용
